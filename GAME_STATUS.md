## 🎮 How to Contribute/Extend

### Adding a New Job
1. Add entry to `src/data/jobsDatabase.js`
2. Create mini-game component in `src/components/jobs/mini-games/`
3. Register in `MINI_GAME_COMPONENTS` map
4. Test gameplay balance

### Adding a New Stock
1. Add entry to `src/data/stocksDatabase.js`
2. Set `eraAvailability`
3. Market will auto-include it

### Adding a New Event
1. Add to `src/data/eventsDatabase.js`
2. Define `type`, `impact`, `probability`
3. Event system will handle it

### Adding a New Era
1. Define in `src/data/historicalPeriods.js`
2. Tag assets with `eraAvailability`
3. Add era-specific events
4. Create welcome screen content
